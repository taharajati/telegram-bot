### Task 1: Add `/help` command for all roles

**Objective:** Add `/help` that shows role-appropriate commands.

**Files:**
- Create: `handlers/help.py`
- Modify: `main.py` (import + register)

**Step 1: Write handler**
```python
# handlers/help.py
from telegram import Update
from telegram.ext import ContextTypes
from utils.helpers import is_super_admin
from handlers.admin.panel import _get_shop_id_for_admin

async def help_command(update: Update, context: ContextTypes.DEFAULT_TYPE):
    user_id = update.effective_user.id
    is_admin = is_super_admin(user_id)
    shop_id = await _get_shop_id_for_admin(user_id)
    
    lines = ["📖 <b>راهنمای دستورات</b>\n"]
    
    lines.append("<b>👤 کاربری (همه):</b>")
    lines.append("/start — منوی اصلی")
    lines.append("/menu — مشاهده دسته‌بندی‌ها")
    lines.append("/cart — سبد خرید")
    lines.append("/my_orders — تاریخچه سفارش‌ها")
    lines.append("/support — پیام به پشتیبانی")
    lines.append("/cancel — لغو عملیات جاری")
    
    if is_admin:
        lines.append("\n<b>🔧 ادمین کل:</b>")
        lines.append("/admin — پنل مدیریت کل")
        lines.append("/orders — سفارش‌های در حال پیگیری")
    elif shop_id:
        lines.append("\n<b>🏪 فروشنده:</b>")
        lines.append("/myshop — پنل مدیریت فروشگاه")
        lines.append("/neworders — سفارش‌های جدید")
        lines.append("/my_panel — تنظیمات و پرداخت")
    else:
        lines.append("\n<i>برای ساخت فروشگاه: /start → 🏪 می‌خوام فروشگاه بسازم</i>")
    
    await update.message.reply_text("\n".join(lines), parse_mode="HTML")
```

**Step 2: Register in main.py**
```python
# Add import
from handlers import help as help_handler

# In _register_customer_handlers
application.add_handler(CommandHandler("help", help_handler.help_command))
```

**Verification:** `pytest tests/test_help.py -v` (create simple test) → PASS

### Task 4: Add `/myshop` command handler

**Objective:** Make `/myshop` work as standalone command (currently only callback).

**Files:**

- Modify: `main.py` (register)

**Step 1: Add in seller_panel.py**

```python
async def seller_panel_command(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """Handle /myshop command."""
    user_id = update.effective_user.id
    from handlers.admin.panel import _get_shop_id_for_admin
    shop_id = await _get_shop_id_for_admin(user_id)
    
    if not shop_id:
        await update.message.reply_text("❌ شما فروشنده‌اید ثبت‌نام نکرده‌اید.")
        return
    
    # Reuse existing logic
    from handlers.admin.panel import admin_command
    await admin_command(update, context)
```
